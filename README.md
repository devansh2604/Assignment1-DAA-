# UCS415 – Design and Analysis of Algorithms  
## Lab Assignment 1 (Week 2 & 3)

This repository contains the implementation of **Divide and Conquer algorithms** as part of **UCS415 (DAA)** Lab Assignment 1.

---

## ✅ Topics Covered

### Core Questions
1. **Binary Search**  
   - Search for a target element in a sorted array using divide and conquer.

2. **Merge Sort**  
   - Sorting of given arrays using merge sort technique.

3. **Quick Sort**  
   - Sorting using partition-based divide and conquer algorithm.

4. **Maximum Subarray Sum**  
   - Finding maximum sum of a contiguous subarray using divide and conquer.

---

## ✅ Additional Questions
1. **Minimize Maximum Bitwise OR (Array Partitioning)**  
   - Divide array into at-most `M` consecutive segments such that the maximum bitwise OR among all segments is minimized.

2. **Longest Good Subsequence (Absolute Difference ≤ 10)**  
   - Find the maximum length subsequence where every pair of elements has an absolute difference of at most 10.

3. **Repeated Median Removal (N-2 operations)**  
   - Perform repeated operations by removing medians from odd-length subarrays.
   - Return the sum of remaining elements.

4. **Speciality of Sequence**
   - A number `A[i]` is called special if a contiguous subarray exists containing exactly `K` numbers strictly greater than `A[i]`.
   - Speciality is the sum of all special numbers.

5. **Minimum Square Size to Fit Rectangles**
   - Find the minimum side length of a square required to fit `N` rectangles of size `W x H` (rotation not allowed).

6. **Closest Pair of Points**
   - Find the closest pair of points and the minimum Euclidean distance using divide and conquer.
